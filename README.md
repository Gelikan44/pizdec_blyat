# Бот izi.market × smmway

Продаёте SMM-услуги на izi.market — бот сам выполняет их через smmway.ru.

**Как работает**
1. Покупатель оплачивает ваш товар на izi.market (например, «1000 подписчиков в Telegram») и указывает ссылку.
2. Бот раз в 30 сек видит новую оплаченную сделку, берёт ссылку и создаёт заказ на smmway по привязанной услуге.
3. Пишет покупателю в чат сделки, выдаёт сделку и присылает вам уведомление в Telegram.
4. Каждые 5 минут проверяет статус на smmway: «выполнено» — сообщает покупателю; отмена/частичное — зовёт вас.

## Установка
```bash
pip install -r requirements.txt
cp .env.example .env     # и заполните ключи
python bot.py
```
Нужен Python 3.10+. Бот должен работать постоянно — запускайте на VPS (screen / systemd / Docker).

## Ключи
- **BOT_TOKEN** — от @BotFather.
- **ADMIN_IDS** — ваш Telegram ID (напишите боту что угодно — он ответит ID).
- **IZI_API_KEY** — izi.market → Настройки → API → новый ключ `izp_…` с правами
  `orders:read, orders:write, products:read, balance:read, chats:read, chats:write`.
  Ключи, выпущенные до 20.10.2026, не умеют выдавать сделки — выпустите новый.
- **SMM_API_KEY** и **SMM_API_URL** — со страницы smmway.ru/developer.

## Первая настройка (в боте)
1. `/products` — список ваших товаров с id.
2. `/services telegram подписчики` — найти услугу на smmway и её id.
3. `/bind <id_товара> <id_услуги> <сколько_за_1_шт>`
   Пример: товар «1000 подписчиков», продаётся поштучно → `/bind 0e33… 1234 1000`.
   Если покупатель берёт 3 шт., бот закажет 3000.
4. В товаре на izi.market добавьте поле, где покупатель указывает ссылку. Бот находит ссылку сам;
   если полей несколько — впишите ключ поля в `LINK_INPUT_KEY`.

## Команды
`/balance` `/orders` `/order id` `/link id ссылка` `/retry id` `/refill id` `/check` `/bindings` `/unbind id`
(id сделки можно сокращать до первых символов)

## Настройки
- `DELIVER_ON=start` — выдать сделку сразу после запуска заказа (у покупателя пойдёт срок подтверждения).
  `complete` — выдать только когда smmway отметит выполнение (надёжнее, но следите за сроком выдачи сделки).
- Тексты сообщений покупателю: переменные `MSG_STARTED`, `MSG_DONE`, `MSG_NEED_LINK` в `.env`.

## Безопасность
- Следите за балансом smmway (`/balance`): без денег заказы не создадутся — бот сообщит об ошибке.
- Если бот перезапустился в момент создания заказа, сделка помечается «ошибка», чтобы не заказать дважды —
  проверьте её на smmway и при необходимости `/retry`.
